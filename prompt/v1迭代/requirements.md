## 1. 项目概述

### 1.1 背景与痛点

在一期视频创作中，AI 语音生成涉及多个平台（IndexTTS、GPT-SoVITS 等），这些引擎通常以 WebUI（Gradio）形式提供。当前工作流存在以下问题：

- **手动操作繁琐**：文案完成后，需人工逐句输入不同平台
- **重复劳动严重**：每句话通常需要多次生成才能确定最佳效果
- **文件管理混乱**：每次生成后需手动下载 → 重命名 → 整理，极易出错
- **多平台切换低效**：不同引擎分散在不同页面，缺乏统一操作入口
- **状态追踪缺失**：无法直观了解哪些句子已生成、哪些待处理

### 1.2 产品目标

打造一款桌面端 AI 语音合成任务管理工具，实现：

1. **统一管理**：在一个界面中管理多个 TTS 引擎
2. **批量自动化**：支持批量提交、队列调度、自动命名
3. **配置持久化**：任务状态与生成配置可追溯、可复现
4. **流畅体验**：内置音频播放器，即时试听效果

### 1.3 目标用户

- 视频创作者、配音师、内容制作者
- 需要批量生成 AI 语音的音频后期人员

## 2. 功能需求

### 2.1 核心概念

#### 2.1.1 任务集（TaskSet）

| 属性 | 说明 |
|------|------|
| 定义 | 一个项目/视频的语音合成任务集合 |
| 存储形式 | 本地目录，目录内包含所有任务配置、输出音频 |
| 包含内容 | 文案编排、引擎选择、各引擎入参配置、生成结果 |

**目录结构示意**：
```
project_voice/
├── taskset.json          # 任务集元信息
├── tasks/
│   ├── task_001.json     # 任务配置（持久化）
│   ├── task_002.json
│   └── ...
└── outputs/
    ├── task_001_你好世界.wav
    ├── task_002_这是测试.wav
    └── ...
```

#### 2.1.2 任务（Task）

| 属性 | 说明 |
|------|------|
| 定义 | 一条完整的语音生成指令 |
| 核心字段 | 任务 ID、文案文本、生成引擎、引擎入参、任务状态、输出音频路径 |
| 状态流转 | `未开始` → `队列中` → `生成中` → `生成完成` / `生成失败` |
| 生命周期 | 创建 → 配置 → 入队 → 生成 → 完成/失败 → （可选）重新生成 |

**状态机图**：
```
未开始 ──[批量生成]──→ 队列中 ──[调度选中]──→ 生成中
                                                    │
                                    ┌───────────────┴───────────────┐
                                    ↓                               ↓
                              生成完成                          生成失败
                                    │                               │
                                    └───[重新生成]──→ 队列中 ←────────┘
```

### 2.2 功能模块

#### 2.2.1 软件配置（Tab 1）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 引擎 URL 配置 | P0 | 为每个引擎配置 WebUI 地址（如 IndexTTS API URL、GPT-SoVITS API URL），支持连接测试 |
| 引擎入参模板 | P1 | 可预设各引擎的默认入参（情感模式、情感向量默认值等），新建任务时自动填入 |
| 任务集管理 | P0 | 创建/切换/删除任务集，选择任务集存储目录 |
| 全局设置 | P2 | 音频输出格式、并发数限制、下载超时时间等 |

#### 2.2.2 任务列表（Tab 2）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 任务列表视图 | P0 | 表格/列表展示所有任务，列包含：序号、任务 ID、文案摘要、引擎、状态（带颜色标识）、操作按钮 |
| 多选与批量操作 | P0 | 支持勾选多选，批量操作栏提供：批量生成、批量删除、批量下载 |
| 排序 | P1 | 支持按任务 ID、状态、创建时间排序 |
| 筛选 | P2 | 支持按状态、引擎类型筛选任务 |
| 任务详情面板 | P0 | 点击选中任务后展示详情：文案编辑、引擎选择、引擎专属配置块、参考音频选择、任务状态 |
| 任务 CRUD | P0 | 新建任务、编辑任务、删除任务、下载生成音频 |
| 全局播放器 | P0 | 顶部固定播放栏，播放选中任务的生成音频或参考音频；支持暂停；新播放自动停止旧播放 |
| 任务队列视图 | P1 | 可视化展示当前队列长度、正在生成的任务、队列进度 |

### 2.3 引擎配置

#### 2.3.1 IndexTTS

**API 类型**：Gradio API（优先级判断），若非 Gradio 则根据实际响应判断

| 入参 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 参考音频（reference_audio） | File/Path | ✅ | 提供音色的参考音频文件 |
| 目标文案（text） | String | ✅ | 需要合成的文本内容 |
| 情感指定模式（emotion_mode） | Enum | ✅ | `same_as_ref` / `emotion_ref_audio` / `emotion_vector` |
| 情感入参 | - | 视模式而定 | 见下表 |

**情感入参（按模式）**：

| 模式 | 情感入参 | 类型 | 说明 |
|------|----------|------|------|
| `same_as_ref` | 无 | - | 与参考音频保持相同情感 |
| `emotion_ref_audio` | emotion_audio | File/Path | 上传情感参考音频 |
| `emotion_vector` | emotion_control_weight | Float(0~1) | 情感控制权重 |
| | calm | Float(0~1) | 平静 |
| | surprised | Float(0~1) | 惊讶 |
| | melancholic | Float(0~1) | 忧郁 |
| | disgusted | Float(0~1) | 厌恶 |
| | afraid | Float(0~1) | 害怕 |
| | sad | Float(0~1) | 悲伤 |
| | angry | Float(0~1) | 愤怒 |
| | happy | Float(0~1) | 快乐 |

#### 2.3.2 GPT-SoVITS

| 入参 | 类型 | 必填 | 说明 |
|------|------|------|------|
| API URL | String | ✅ | 先占位，待对接后确定 |
| 参考音频 | File/Path | ✅ | （待对接后细化） |
| 目标文案 | String | ✅ | （待对接后细化） |
| 其他参数 | - | - | 预留，待对接后补充 |

#### 2.3.3 引擎扩展设计

- 引擎以**插件/适配器模式**设计，新增引擎只需实现统一接口
- 接口包含：API 连接检测、参数定义、生成请求、结果解析

### 3.2 用户操作流程

#### 3.2.1 首次使用

1. 打开应用 → 进入「配置」Tab
2. 配置 IndexTTS API URL → 点击「测试连接」确认可访问
3. 配置 GPT-SoVITS API URL → 点击「测试连接」确认可访问
4. 创建/选择任务集目录

#### 3.2.2 日常使用

1. 在「任务列表」Tab 中新建任务
2. 填写文案 → 选择引擎 → 配置引擎参数（参考音频、情感等）
3. 保存任务配置
4. 批量选中待生成任务 → 点击「批量生成」
5. 任务进入队列，自动逐个生成
6. 生成完成后，通过全局播放器试听
7. 满意后批量下载音频文件

### 3.3 交互细节

| 场景 | 交互行为 |
|------|----------|
| 选中任务 | 点击任务行 → 右侧/下方展示详情面板 → 任务行高亮 |
| 批量选择 | 勾选 Checkbox，支持全选/反选 |
| 引擎切换 | 任务详情中切换引擎下拉 → 参数面板实时切换 |
| 情感模式切换 | 选择不同情感指定模式 → 情感入参区域动态渲染 |

## 4. 技术方案

### 4.1 环境管理

- 使用 **NV（Node Version Manager）** 管理 Python 虚拟环境
- 项目根目录提供 `pyproject.toml`，声明依赖，锁定版本

### 4.2 技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| 语言 | Python 3.11+ | 生态丰富，TTS 相关库支持好 |
| GUI 框架 | **NiceGUI** 或 **PySide6** | NiceGUI：开发效率高、组件丰富、内置音频播放；PySide6：原生桌面体验好、可定制性强 |
| 音频播放 | `pygame` 或 `pydub` + `simpleaudio` | 支持 WAV/MP3 播放、暂停 |
| HTTP 客户端 | `httpx`（异步）或 `requests` | 调用引擎 WebUI API |
| 任务队列 | `asyncio.Queue` | 内置队列，无需额外依赖 |
| 持久化 | JSON 文件 | 轻量，适合任务级配置存储 |
| 文件管理 | `pathlib` + `aiofiles` | 跨平台路径处理 |
| 打包分发 | `PyInstaller` 或 `Nuitka` | 生成独立可执行文件 |

**GUI 框架推荐**：优先推荐 **PySide6**，原因是：
- 原生表格（QTableWidget）支持复杂列表交互（排序、勾选、右键菜单）
- QMediaPlayer 可直接实现音频播放
- Tab 切换、动态表单切换天然支持
- 打包体积可控

### 4.4 数据模型

#### 4.4.1 TaskSet（任务集）

```python
@dataclass
class TaskSet:
    id: str                     # UUID
    name: str                   # 任务集名称
    directory: Path             # 任务集目录路径
    tasks: list[Task]           # 包含的任务列表
    created_at: str             # 创建时间 ISO 8601
    updated_at: str             # 更新时间
```

#### 4.4.2 Task（任务）

```python
@dataclass
class Task:
    id: str                     # 短 ID，如 "task_001"
    text: str                   # 目标文案
    engine: str                 # 引擎标识: "indextts" | "gpt_sovits"
    status: TaskStatus          # 状态枚举
    engine_params: dict         # 引擎入参（因引擎而异）
    output_audio_path: str      # 生成音频路径（生成完成后填充）
    generation_config: dict     # 生成时的快照配置（生成完成后保存）
    error_message: str          # 错误信息（生成失败时）
    created_at: str
    updated_at: str

class TaskStatus(Enum):
    PENDING = "未开始"
    QUEUED = "队列中"
    GENERATING = "生成中"
    COMPLETED = "生成完成"
    FAILED = "生成失败"
```

#### 4.4.3 引擎参数（IndexTTS 示例）

```python
@dataclass
class IndexTTSParams:
    reference_audio: str        # 参考音频路径
    text: str                   # 文案
    emotion_mode: str           # same_as_ref | emotion_ref_audio | emotion_vector
    # emotion_ref_audio 模式
    emotion_audio: str = None
    # emotion_vector 模式
    emotion_control_weight: float = 0.5
    calm: float = 0.0
    surprised: float = 0.0
    melancholic: float = 0.0
    disgusted: float = 0.0
    afraid: float = 0.0
    sad: float = 0.0
    angry: float = 0.0
    happy: float = 0.0
```

### 4.5 核心流程

#### 4.5.1 任务生成流程

```
用户点击「批量生成」
    │
    ▼
遍历选中的「未开始」任务 → 加入 task_queue
    状态更新: 未开始 → 队列中
    持久化到 task_N.json
    │
    ▼
task_queue.get() 取出队首任务
    状态更新: 队列中 → 生成中
    │
    ▼
根据任务引擎类型，调用对应 EngineAdapter.generate()
    ├─ 成功 ──→ 状态: 生成中 → 生成完成
    │           保存 audio 到 outputs/ 目录
    │           保存 generation_config 快照
    │           ✅ 通知 UI 更新
    │
    └─ 失败 ──→ 状态: 生成中 → 生成失败
                记录 error_message
                ❌ 通知 UI 更新
    │
    ▼
继续处理下一个队列任务（循环）
```

#### 4.5.2 引擎 API 对接策略

```
引擎 API URL 配置
    │
    ▼
探测 API 类型:
    ├─ 尝试访问 /api/predict (Gradio API 特征)
    │   └─ 成功 → 使用 Gradio 适配器
    ├─ 尝试访问 /docs 或 /openapi.json
    │   └─ 成功 → 使用 OpenAPI 自动适配
    └─ 均失败 → 标记 URL 不可用，提示用户检查
    │
    ▼
确定 API 端点与参数映射
    │
    ▼
封装为 EngineAdapter.generate() 统一调用
```

### 4.6 文件命名规范

```
{task_id}_{sanitized_text}.{ext}

示例:
task_001_你好世界.wav
task_002_欢迎收看本期视频.wav
task_003_test_hello_world.wav

sanitized_text 规则:
1. 移除所有特殊字符（保留中文、英文、数字）
2. 空格替换为下划线
3. 最大长度限制 50 字符
```

## 7. 附录

### 7.1 术语对照

| 术语 | 英文 | 说明 |
|------|------|------|
| 任务集 | TaskSet | 一组语音生成任务的集合，对应一个项目 |
| 任务 | Task | 单条语音生成指令 |
| 引擎 | Engine | 第三方 TTS 服务（IndexTTS、GPT-SoVITS） |
| 参考音频 | Reference Audio | 用于提供音色/情感参考的音频文件 |
| 情感向量 | Emotion Vector | 一组 0~1 之间的浮点数，用于精细控制情感 |
| 生成配置快照 | Generation Config Snapshot | 生成完成时保存的完整参数副本，便于复现 |

### 7.2 风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|----------|
| Gradio API 版本变化 | 引擎调用失败 | API 探测机制 + 版本兼容层 |
| 非 Gradio API | 对接方式不同 | 预留 OpenAPI/通用 HTTP 适配方案 |
| 大文件传输超时 | 生成失败 | 支持配置超时时间 + 断点续传（重试） |
| 多个引擎并发调用 | API 限流 | 任务队列串行调度，可配置队列间隔时间 |

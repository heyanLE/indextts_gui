## 2. 功能需求

### 2.1 新增概念：配方（Recipe）

#### 定义

配方是一套**引擎类型 + 完整入参配置**的命名快照，用户可将调试好的参数保存复用。

**数据模型**：

```python
@dataclass
class Recipe:
    id: str                     # UUID
    name: str                   # 配方名称（用户自定义）
    engine: str                 # 引擎标识 (indextts / gpt_sovits)
    engine_params: dict         # 引擎全部入参键值对
    created_at: str             # ISO 8601
    updated_at: str             # ISO 8601
```

**存储**：应用级配置目录 `{AppData}/indextts-gui2/recipes.json`（跨任务集复用）。

### 2.2 功能模块详解

#### R1 — 配方管理 Tab（P0，新增）

| 功能 | 描述 |
|------|------|
| 配方列表 | 表格展示所有配方，列：名称、引擎类型、创建时间、更新时间 |
| 添加配方 | 弹出编辑对话框，输入名称 + 选择引擎 + 填写参数 → 保存 |
| 编辑配方 | 双击行或点击编辑 → 编辑对话框 → 修改保存 |
| 复制配方 | 选中行 → 复制 → 生成副本（名称追加"_副本"） |
| 删除配方 | 单行 × 按钮或右键删除，需确认 |
| 批量删除 | 勾选多行 → 批量删除 → 确认后执行 |
| 搜索筛选 | [P2] 按名称搜索、按引擎筛选 |

#### R2 — 任务详情配方选择框（P0）

| 功能 | 描述 |
|------|------|
| 位置 | 任务详情面板引擎配置区**上方**新增 QComboBox 配方选择器 |
| 应用配方 | 选择配方 → 当前任务引擎类型和全部入参立即替换为配方配置 |
| 按钮重排 | 原"回溯结果入参"按钮移至配方选择框后方，改名为"使用当前生成音频配方"，功能不变 |

#### R3 — 配方 → 自定义自动检测（P0）

用户选择配方后，若手动修改任意引擎参数，配方下拉**立刻切换为灰色斜体"（自定义）"**。

**触发条件**：任一参数值与当前配方对应值不一致（含切换引擎类型）。

**恢复**：重新从下拉选择配方即恢复默认值。

#### R4 — 保存当前配方按钮（P0）

任务详情面板新增"保存为配方"按钮：

1. 点击 → 弹出命名对话框
2. 输入配方名称 → 确认
3. 若名称冲突，提示是否覆盖
4. 保存后刷新配方列表和下拉

#### R5 — 任务列表试听按钮（P0）

| 功能 | 描述 |
|------|------|
| 位置 | 任务表格每行新增 🔊 试听按钮 |
| 条件 | 仅"生成完成"状态显示，其他状态灰显或不展示 |
| 行为 | 点击 → 全局播放器播放该任务生成音频 |

#### R6 — 任务锁定功能（P0）

| 功能 | 描述 |
|------|------|
| 位置 | 任务表格每行新增 🔒/🔓 按钮 |
| 条件 | **仅生成完成的任务**展示锁定按钮 |
| 效果 | 锁定后右侧详情面板所有编辑控件（文案、引擎、参数）变为只读/禁用 |
| 解锁 | 再次点击恢复可编辑 |
| 持久化 | [P1] 锁定状态保存到任务 JSON（`locked: bool`） |

#### R7 — 生成中 Loading 动画（P0）

任务状态为"生成中"时，状态列不再展示文字"生成中"，改为显示旋转 Loading 动画指示器（QWidget 自定义绘制圆弧旋转，或 QProgressBar 跑马灯模式）。

状态变为完成/失败时，动画停止，恢复对应状态展示。

#### R8 — 任务队列可视化（P0）

| 功能 | 描述 |
|------|------|
| 位置 | 全局播放器**下方**新增横向任务队列条 |
| 内容 | 横向排列队列中所有任务的**文案**（不展示 ID/引擎等） |
| 排序 | 第一个为"生成中"，后续按入队顺序 |
| 样式 | 每个胶囊固定宽度 150px，文案超出省略号截断 |
| 滚动 | [P1] 任务过多时支持横向滚动 |
| 空状态 | 队列为空时隐藏该区域 |

#### R9 — 单任务生成直接入队（P0）

点击单个任务"生成"按钮 → **不再弹出"将会开始生成"确认弹窗** → 直接入队，通过队列可视化和状态变化提供视觉反馈。

批量生成保留简单提示（或也一并取消弹窗，均为直接入队）。

### 4.4 向下兼容

| 场景 | 策略 |
|------|------|
| 旧任务无 `locked` 字段 | `from_dict` 时 `data.setdefault("locked", False)` |
| 旧任务无 recipe 引用 | 配方下拉默认 "（自定义）"，不影响编辑 |
| `recipes.json` 不存在 | RecipeManager 首次加载创建空文件 |
| 删除后引擎不存在 | 配方仍保留，切换时提示引擎未配置 |

## 6. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| QSS 重写导致已有组件显示异常 | UI 错乱 | 渐进迁移：先主框架 → 再逐个组件调优 |
| 配方参数比较频繁触发（性能） | UI 卡顿 | 仅在参数值实际变更时触发（利用信号值变化判断），批量更新时暂停监听 |
| 队列可视化大量任务时布局问题 | 横向溢出 | 固定胶囊宽度 + QScrollArea 横向滚动 |
| 旧任务集数据无 locked 字段 | 加载失败 | `data.setdefault("locked", False)` 向后兼容 |
| 配方引用已删除的引擎类型 | 配方不可用 | 配方仍保留，应用时提示"引擎未配置" |
